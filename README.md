# 2gether: คู่มือตั้งค่า (ทำครั้งเดียว ประมาณ 15 นาที)

เว็บนี้ใช้ 2 บริการฟรี: **Supabase** (เก็บข้อมูล ล็อกอิน เรียลไทม์) และ **Netlify** (ให้เว็บออนไลน์)

## ส่วนที่ 1: Supabase

1. เข้า supabase.com แล้วสมัคร (ใช้ Google หรือ GitHub ก็ได้)
2. กด **New project** ตั้งชื่ออะไรก็ได้ ตั้งรหัสฐานข้อมูล (เก็บไว้) เลือก Region **Southeast Asia (Singapore)** แล้วรอสร้างเสร็จ
3. เมนูซ้าย **SQL Editor** > **New query** เปิดไฟล์ `supabase/schema.sql` ในโฟลเดอร์นี้ คัดลอกทั้งหมดไปวาง แล้วกด **Run** ต้องขึ้นว่า Success
   - ไฟล์นี้สร้างตารางโปรไฟล์ ล็อกให้มีได้แค่ 2 บัญชี และเปิดห้องเรียลไทม์ส่วนตัว
   - **ไฟล์ที่ต้องรันเพิ่ม (รันตามลำดับ ครั้งละไฟล์ รันซ้ำได้ไม่พัง):** `supabase/schema-step2.sql` (ตัวละคร บ้าน แมว), `schema-step3.sql` (Bond และแจ้งเตือน), `schema-step4.sql` (แชทและพักแจ้งเตือน), `schema-step5.sql` (ห้องนอน Bond รายวัน และวันครบหลักไมล์), **`schema-final.sql`** (มินิเกมทั้งหมด เกมคลาสสิก ของสะสม และสมุดความทรงจำ รันครั้งเดียวจบ ไม่มีไฟล์ SQL ถัดไปอีก) ถ้าไฟล์ไหนยังไม่ได้รัน เว็บจะบอกในหน้าที่เกี่ยวข้อง
4. เมนูซ้าย **Authentication** > **Sign In / Providers** (หรือ **Providers**) > **Email** แล้ว **ปิด "Confirm email"** กดบันทึก
   - ถ้าไม่ปิด จะต้องรออีเมลยืนยันทุกครั้งที่สมัคร
5. เมนูซ้าย **Project Settings** > **API** (หรือ **API Keys**) คัดลอก 2 ค่า:
   - **Project URL** (เช่น `https://abcdxyz.supabase.co`)
   - คีย์ **anon public** (หรือ **publishable**) ที่ขึ้นต้นด้วย `eyJ...` หรือ `sb_publishable_...`
   - ห้ามใช้คีย์ **service_role** หรือ **secret** เด็ดขาด
6. เปิดไฟล์ `js/config.js` ด้วย Notepad วางค่าทั้งสองลงในเครื่องหมายคำพูด แล้วบันทึก:
   ```js
   export const SUPABASE_URL = 'https://abcdxyz.supabase.co';
   export const SUPABASE_ANON_KEY = 'eyJ...';
   ```
7. (ถ้าเห็นตัวเลือก) **Realtime** > **Settings** ให้ปิด **Allow public access** เพื่อให้ห้องเรียลไทม์ใช้ได้เฉพาะคนที่ล็อกอิน

## ส่วนที่ 1.5: ระบบแจ้งเตือน "กลับบ้านกันเถอะ" (ทำครั้งเดียว ประมาณ 10 นาที)

ปุ่มนี้ใช้ตอนอีกคนไม่ได้เปิดเว็บ ต้องมีโค้ดฝั่งเซิร์ฟเวอร์ส่งแจ้งเตือน เราใช้ Supabase Edge Function (ไม่ต้องติดตั้งโปรแกรมอะไร)

1. **ใส่ความลับ:** Supabase > เมนูซ้าย **Edge Functions** > แท็บ **Secrets** > **Add new secret** ใส่ 3 ค่าจากไฟล์ `2gether-secrets.txt` ที่ส่งแยกให้ (ชื่อต้องตรงเป๊ะ) คือ `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`, `VAPID_SUBJECT` แล้วกดบันทึก
2. **สร้างฟังก์ชัน:** Edge Functions > **Deploy a new function** > **Via Editor** ตั้งชื่อ `nudge-push` (พิมพ์ให้ตรง) ลบโค้ดตัวอย่างทิ้งทั้งหมด แล้วเปิดไฟล์ `supabase/functions/nudge-push/index.ts` คัดลอกทั้งไฟล์ไปวาง
3. กด **Deploy function** รอจนเสร็จ
4. เข้าหน้าของฟังก์ชัน `nudge-push` > **Details** (หรือ Settings) หาสวิตช์ **Verify JWT** แล้ว **ปิด** (ฟังก์ชันตรวจตัวตนเองอยู่แล้ว) กดบันทึก
5. ให้ทั้งสองคนเปิดเว็บ ไปที่ **ตั้งค่า > แจ้งเตือน** แล้วเปิดสวิตช์ กดอนุญาตตอนเบราว์เซอร์ถาม (iPhone ต้องติดตั้งลงหน้าจอโฮมก่อน ดูส่วนที่ 4)
6. ทดสอบ: ให้คนหนึ่งปิดเว็บ อีกคนกดปุ่ม **กลับบ้านกันเถอะ** ที่ห้องนั่งเล่น

**อัปเดตฟังก์ชันให้เป็นเวอร์ชันล่าสุด (ทำหลังรัน SQL ใหม่ทุกครั้งที่ผมส่งไฟล์ `index.ts` ใหม่มา):** Edge Functions > `nudge-push` > แท็บ **Code** ลบโค้ดเก่าทั้งหมด คัดลอก `supabase/functions/nudge-push/index.ts` ไปวางใหม่ แล้วกด **Deploy updates** (Secrets และ Verify JWT ที่ตั้งไว้แล้วไม่ต้องทำใหม่)

## ส่วนที่ 2: Netlify

1. เข้า netlify.com แล้วสมัคร
2. ไปที่ **Add new site** > **Deploy manually** (ลากวาง)
3. ลากโฟลเดอร์ **2gether** ทั้งโฟลเดอร์ (ที่มี `index.html` อยู่ข้างใน และแก้ `js/config.js` แล้ว) ไปวางในช่อง
4. รอสักครู่ จะได้ที่อยู่เว็บ เช่น `https://ชื่อสุ่ม.netlify.app` เปลี่ยนชื่อได้ที่ **Site configuration** > **Change site name**
5. ทุกครั้งที่ฉันส่งไฟล์ใหม่ ให้ลากโฟลเดอร์ใหม่ไปวางที่ **Deploys** ของเว็บเดิม (ไม่ใช่สร้างเว็บใหม่) ข้อมูลและบัญชีไม่หาย

## ส่วนที่ 3: สร้างบัญชีสองคน

1. เปิดเว็บ กด **สร้างบัญชี** ใส่อีเมลกับรหัสผ่านของคุณ แล้วตั้งชื่อเล่นกับเลือกฤดู
2. ให้แฟนเปิดเว็บบนเครื่องของเขา สร้างบัญชีด้วยอีเมลของเขา
3. หลังมี 2 บัญชี ระบบปิดรับสมัครอัตโนมัติ คนที่ 3 สร้างบัญชีไม่ได้
4. ครั้งแรกแต่ละคนจะได้สร้างตัวละคร คนแรกตั้งชื่อ+สีแมว อีกคนกดยืนยัน (หรือเสนอใหม่) แล้วเข้าบ้านได้
5. ในห้องนั่งเล่น แตะพื้นเพื่อเดิน แตะโซฟาเพื่อนั่ง แตะแมวเพื่อลูบ ถ้าอีกคนอยู่ห้องนี้ จะเห็นเขาเดินสด และแมวตัวเดียวกันในทั้งสองเครื่อง
6. แชท: กดไอคอนข้อความมุมขวาบน แตะที่ข้อความเพื่อกดรีแอ็กชันหรือลบข้อความของตัวเอง ถ้าอีกคนไม่ได้เปิดเว็บ เครื่องเขาจะเด้ง "มีข้อความใหม่" (ไม่แสดงเนื้อหา รวมเป็น 1 ครั้งต่อ 3 นาที) และพักแจ้งเตือนได้ที่ตั้งค่า > แจ้งเตือน
7. ห้องนอน (แถบล่าง > ห้องนอน): กด "ราตรีสวัสดิ์" ตัวละครขึ้นเตียงนอนและไฟหรี่ กด "สวัสดีตอนเช้า" ลุกขึ้น ทั้งสองปุ่มได้ Bond +2 คนละ 1 ครั้งต่อวัน (นับวันตามเวลาไทย) ปุ่ม "ปลุก" และ "ชวนเข้านอน" เด้งข้อความสดถ้าอีกคนออนไลน์ ไม่งั้นส่งแจ้งเตือนเข้าเครื่อง (ไม่เกิน 1 ครั้งต่อ 10 นาที) แมวจะมาอยู่ห้องนอนเฉพาะตอนที่ทั้งสองคนอยู่ห้องนี้
8. วันเริ่มคบ: ตั้งที่ตั้งค่า > วันเริ่มคบ (ใช้ร่วมกัน วันที่ตั้งนับเป็นวันที่ 1) ตัวนับ "อยู่ด้วยกันมา N วัน" ขึ้นที่ห้องนอนและห้องนั่งเล่น ครบ 100, 200, 300 วันและทุกครบปีมีการ์ดฉลองและ Bond +10 (ครั้งเดียวต่อหลักไมล์)
9. ห้องครัว (แถบล่าง > ครัว): เดินเล่นได้เหมือนห้องอื่น และมีเกมทำอาหาร 2 เกม ต้องอยู่ในห้องครัวทั้งสองคนถึงเริ่มได้ กดเกมแล้วอีกคนจะเห็นคำชวน กด "เล่นเลย" แล้วนับถอยหลัง 3 วินาที
   - **ทำอาหารให้แมว** (75 วินาที): คนที่ชวนหั่น อีกคนผัด แตะรัวๆ ส่งจานให้แมวที่หิว
   - **ทำอาหารด้วยกัน** (90 วินาที): ใบสั่ง 4 ขั้น แต่ละขั้นเป็นของคนละคน กดสลับกันให้ทันก่อนอาหารไหม้
   - จบรอบได้ดาว 1-3 ดวง ได้ Bond +3 ต่อเกมต่อวัน (ครั้งแรกของวัน) เล่นซ้ำได้ไม่จำกัด ผลเก็บไว้ถาวร
   - ถ้าอีกคนไม่อยู่ครัว: ออนไลน์อยู่ห้องอื่น = เด้งข้อความสดชวนเขา ปิดเว็บอยู่ = ส่งแจ้งเตือนชวน (ไม่เกิน 1 ครั้งต่อ 10 นาที ต้องอัปเดต Edge Function ตามด้านบน)
10. สวน (แถบล่าง > สวน): เดินเล่นได้ มี 4 เกม เล่นแบบเดียวกับครัว (ต้องอยู่ในห้องสวนทั้งคู่)
   - **ปลูกดอกไม้** (60 วินาที): คนหนึ่งขุดหลุมหยอดเมล็ด อีกคนรดน้ำ ดอกไม้ที่โตแล้วเข้า "สวนดอกไม้ของเรา" (12 ชนิด)
   - **ตกปลา** (75 วินาที): คนหนึ่งเหวี่ยงเบ็ดและกระตุกให้ทันตอนปลากิน อีกคนกดค้างดึงสายให้แรงตึงอยู่ในโซนเขียว ปลาที่ได้ไปอยู่ใน "ตู้ปลา" ในสวน (12 ชนิด มีหายากและหายากมาก)
   - **จับหิ่งห้อย** (60 วินาที): หิ่งห้อยบินทีละตัว ต้องแตะพร้อมกันทั้งสองคนภายใน 1.5 วินาทีถึงจะจับได้
   - **เก็บดาว** (60 วินาที): ดาวตกจากฟ้า คนหนึ่งลากตะกร้ารับ อีกคนกดเสกลมซ้าย/ขวาให้ดาวเอียงเข้าตะกร้า
   - ดวงดาวจากสองเกมกลางคืนไปอยู่ใน "ท้องฟ้าดูดาว" ในหน้าสวน (12 ชนิด)
   - ของสะสมเก็บถาวร ไม่ลบ ยิ่งได้ดาวมาก ยิ่งมีโอกาสได้ชนิดหายาก
11. ห้องเกม (แถบล่าง > ห้องเกม): เกมคลาสสิก 11 เกม เล่นสดพร้อมกันสองคน ต้องอยู่ห้องนี้ทั้งคู่ กดเกมเพื่อชวน ได้ Bond +3 ต่อเกมต่อวัน (ครั้งแรกของวัน)
   - XO, Connect 4, โอเทลโล, หมากฮอส, จุดต่อจุด, เรือรบ, เป่ายิ้งฉุบ, จับคู่ภาพ, ทายคำ (ช่วยกันทาย), ปิงปอง, หมากรุก (เต็มกติกา)
   - ปิงปองเป็นเกมสด ใช้เน็ตดีทั้งคู่ถึงจะลื่น เกมที่เหลือผลัดกันเดิน
12. สมุดความทรงจำ (แถบล่าง > สมุด): เส้นเวลาวันสำคัญ (วันเริ่มคบ วันครบ 100/200/300 วัน และวันครบถัดไป) บันทึกสั้นๆ ที่เขียนได้ทั้งคู่ (ลบได้เฉพาะของตัวเอง) และสรุปของสะสมที่เจอแล้ว
13. แถบ Bond ด้านบนเพิ่มทุก 5 นาทีที่อยู่บ้านพร้อมกัน (สูงสุด 30 แต้มต่อวัน) และโบนัสเมื่อสองคนลูบแมวไล่เลี่ยกัน

## หน้าตาเวอร์ชันใหม่ (Cozy storybook)

- ฟอนต์ **Itim** เก็บไว้ในโฟลเดอร์ `fonts/` แล้ว ไม่ต้องโหลดจาก Google (ใบอนุญาต OFL อยู่ที่ `fonts/OFL.txt`)
- มือถือ: เมนูล่างมี 5 ห้อง ส่วนสมุดกับตั้งค่าอยู่ปุ่มบนหัวเว็บ แตะรูปตัวละครสองคนบนหัวเว็บเพื่อเปิดสมุด
- แท็บเล็ตและคอม (กว้าง 768px ขึ้นไป): เมนูย้ายไปเป็นแถบข้างซ้าย
- คอมจอกว้าง (1200px ขึ้นไป): แชทเปิดค้างไว้ข้างขวาทุกห้อง ข้อความนับว่าอ่านแล้วเมื่อแท็บเปิดอยู่

## ตั้งค่าดูทีวีและฟังเพลง

ใส่ค่าทั้งหมดใน `js/config.js` แล้ว deploy ใหม่ ถ้ายังไม่ใส่ ปุ่มทีวีและเพลงจะบอกว่าขาดอะไร โดยแอปส่วนอื่นยังใช้ได้ตามปกติ ไม่ต้องรัน SQL เพิ่ม

### 1. คีย์ YouTube (ฟรี ใช้กับหน้ามาแรงและการค้นหา)

1. เข้า https://console.cloud.google.com แล้วสร้างโปรเจกต์ใหม่ เช่นชื่อ `2gether`
2. ไปที่ APIs & Services > Library ค้นหา **YouTube Data API v3** แล้วกด Enable
3. ไปที่ APIs & Services > Credentials กด Create credentials > API key
4. กดแก้คีย์ที่ได้:
   - ที่ Application restrictions เลือก Websites แล้วใส่ `https://ชื่อเว็บของคุณ.netlify.app/*`
   - ที่ API restrictions เลือก YouTube Data API v3
5. คัดลอกคีย์ไปใส่ `YOUTUBE_API_KEY`

โควตาฟรีวันละ 10,000 หน่วย:
- ค้นหา 1 ครั้งใช้ 100 หน่วย หรือราว 100 ครั้งต่อวัน แอปเก็บผลค้นหาไว้ 1 วัน ค้นคำเดิมซ้ำจึงไม่เสียโควตา
- หน้ามาแรง ช่อง และเพลย์ลิสต์ ใช้ครั้งละ 1 หน่วย
- ถ้าไม่ใส่คีย์ ยังดูด้วยกันได้ผ่านแท็บ "วางลิงก์"

### 2. เชื่อม YouTube (ไม่บังคับ ใช้ดูช่องที่ติดตามและเพลย์ลิสต์ของตัวเอง)

1. ในโปรเจกต์เดียวกัน ไปที่ Google Auth Platform
   1. ตั้งค่า Branding ใส่ชื่อแอปและอีเมล
   2. ที่ Audience เลือก External แล้วเพิ่มอีเมล Google ของทั้งสองคนเป็น Test users
2. ที่ Data Access กด Add scopes แล้วเพิ่ม `.../auth/youtube.readonly`
3. ไปที่ Clients กด Create client:
   - เลือกประเภท Web application
   - ที่ Authorized JavaScript origins ใส่ `https://ชื่อเว็บของคุณ.netlify.app`
4. คัดลอก Client ID ไปใส่ `GOOGLE_CLIENT_ID`
5. แต่ละคนกด "เชื่อม" ที่ ตั้งค่า > บัญชีที่เชื่อม > YouTube ครั้งเดียว

ถ้าอยากดูไม่มีโฆษณา ให้ล็อกอิน YouTube Premium ในเบราว์เซอร์ของเครื่องนั้นไว้ด้วย ส่วนนี้ YouTube เป็นคนจัดการเอง แอปเราไม่เกี่ยว

### 3. Spotify (ต้องมี Spotify Premium แบบเต็ม เช่น Duo)

1. ล็อกอิน https://developer.spotify.com/dashboard ด้วยบัญชี Premium แล้วกด Create app
2. ใส่ข้อมูลแอป:
   - Redirect URIs: ใส่ `https://ชื่อเว็บของคุณ.netlify.app/` ต้องตรงทุกตัวอักษร รวมถึง `/` ท้ายสุด
   - ติ๊ก **Web API** และ **Web Playback SDK**
3. เปิด Settings > User Management แล้วเพิ่มชื่อและอีเมล Spotify ของทั้งสองคน แอปทดสอบรับได้สูงสุด 5 คน
4. คัดลอก Client ID ไปใส่ `SPOTIFY_CLIENT_ID` (ไม่ต้องใช้ Client secret)
5. แต่ละคนกด "เชื่อม" ที่ ตั้งค่า > บัญชีที่เชื่อม > Spotify ครั้งเดียว

ข้อควรรู้:
- ถ้า Premium ของบัญชีเจ้าของแอปหมดอายุ แอปจะหยุดทำงานจนกว่าจะต่ออายุ
- บนมือถือ ถ้าสลับแอปหรือปิดจอ เบราว์เซอร์บางรุ่นจะหยุดเพลงเอง
- การเชื่อมจำไว้ในเครื่องที่กดเชื่อม ถ้าใช้หลายเครื่องต้องกดเชื่อมทีละเครื่อง

- ปุ่ม "ทดสอบแจ้งเตือน" ในตั้งค่า ส่งแจ้งเตือนมาหาเครื่องตัวเอง
- แจ้งเตือนทุกเครื่องที่เปิดไว้ (มือถือ + คอม) ไม่ใช่แค่เครื่องล่าสุด
- เปิดแอปทุกครั้ง แอปยืนยันเครื่องนี้กับเซิร์ฟเวอร์ให้เอง รหัส VAPID เปลี่ยนก็สมัครใหม่ให้เอง
- ปุ่มรีเฟรช: บนหัวเว็บ (เฉพาะแอปที่ติดตั้งไว้) และในหน้าตั้งค่า
- หอมแก้ม: ยืนห่างขึ้นให้เห็นการโน้มตัวชัด (เดิมตัวบังกันจนมองไม่เห็น) และมีคำว่า "จุ๊บๆ"

## ย้ายจาก Netlify ไป GitHub Pages
1. github.com > New repository > ตั้งชื่อ (เช่น `2gether`) > Public > Create
2. Add file > Upload files > ลากไฟล์ทั้งหมด**ข้างใน**โฟลเดอร์ `2gether` (ให้ `index.html` อยู่ชั้นบนสุดของ repo) > Commit
   - ไฟล์ `.nojekyll` ต้องขึ้นไปด้วย (ไฟล์ซ่อน ถ้าลากไม่ติด: Add file > Create new file ชื่อ `.nojekyll` ว่างๆ)
   - ห้ามอัป `2gether-secrets.txt` (เป็นความลับ)
3. Settings > Pages > Source: Deploy from a branch > Branch: `main` / `(root)` > Save รอ 1 ถึง 2 นาที จะได้ `https://ชื่อผู้ใช้.github.io/2gether/`
4. แก้ที่อยู่เว็บใหม่ในบริการอื่น:
   - Supabase > Authentication > URL Configuration: Site URL และ Redirect URLs เป็นที่อยู่ใหม่
   - Spotify Developer > แอป > Settings > Redirect URIs: เพิ่ม `https://ชื่อผู้ใช้.github.io/2gether/` (มี / ปิดท้าย)
   - Google Cloud > Credentials > OAuth client: Authorized JavaScript origins เพิ่ม `https://ชื่อผู้ใช้.github.io` (ไม่มี path)
   - Google Cloud > Credentials > API key ของ YouTube > Website restrictions เพิ่ม `https://ชื่อผู้ใช้.github.io/*`
5. ที่อยู่ใหม่ = เครื่องเริ่มใหม่: ล็อกอินใหม่ เปิดแจ้งเตือนใหม่ เชื่อม YouTube ใหม่ iPhone ต้องเพิ่มไอคอนลงหน้าโฮมใหม่ (ข้อมูลบ้าน แชท Bond และการเชื่อม Spotify อยู่ในบัญชี ไม่หาย)
6. อัปเดตครั้งต่อไป: Add file > Upload files ลากไฟล์ที่เปลี่ยนทับ > Commit (ขึ้นเว็บเองใน 1 ถึง 2 นาที)
